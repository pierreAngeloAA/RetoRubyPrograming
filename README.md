# Reto Ruby Programming

Two small Ruby console exercises.

| Folder | What it is | Run |
|---|---|---|
| `game.rb` + `funtion.rb` | Rock, paper, scissors against the computer | `ruby game.rb` |
| `tasks/` | To-do list saved to a CSV file (`tasks.csv`), with a console menu | `cd tasks && ruby main.rb` |

Note: `tasks/main.rb` rewrites `tasks.csv` with 10 sample tasks every time it starts.
